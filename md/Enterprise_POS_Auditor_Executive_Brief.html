System Checker

What This Tool Does:
This tool is used to automatically check software versions, file sizes, website & API URLs, and system health across store machines without requiring manual logins.

2. What It Checks
🔍 1. Software Version Check
Reads the version release file on each machine to confirm the exact software version is installed and ready for billing.
📁 2. File Size & Info Check
Checks if deployment files exist, verifies their exact file size down to the byte, and confirms the date and time they were last updated.
🌐 3. URL & API Connectivity Check
Tests whether the machines can reach required payment URLs, loyalty services, and central head-office server endpoints.
🩺 4. System Health Diagnostics
Inspects machine uptime, available RAM memory, remaining hard drive storage, and connected peripherals (receipt printers and barcode scanners).
⚡ Time-Saving Feature: One-Click Re-Check for Failed Machines

If any machines fail due to network blips, the tool exports a list of only those failed machines. The operator can reload that list and re-test only the failed systems in seconds, without wasting time re-testing machines that already passed.

3. What Technology is Used?

The tool was intentionally built with lightweight, dependable technologies so it can run immediately on any work computer without complex setups:

Technology What It Is What It Does in This Project
Python Core Programming Language Powers the entire application logic, data handling, and automation cleanly and reliably.
Paramiko Shell (SSH Network Library) Handles remote shell connections to store systems to run checks securely over the private network.
Tkinter Built-in Desktop GUI Library Creates the clean, easy-to-use desktop user interface with buttons, live progress bars, and search filters.
Multi-Threading Parallel Execution Engine Checks multiple store systems at the same time so full audits complete in seconds instead of minutes.
Native Excel Engine Built-in Zipfile & XML Parser Generates clean Microsoft Excel (.xlsx) and CSV files directly without requiring Excel to be installed.
PyInstaller Application Packager Packages everything into a single double-clickable executable (.exe). Zero Python installation needed.

Summary
  • System Checker is an automated desktop tool built in Python to remotely inspect retail store machines in parallel without requiring manual logins.
  • It connects securely via Shell (Paramiko SSH) to verify software versions, deployment file sizes, website/API URLs, and system health (RAM, disk space, uptime).
  • Built-in multi-threading scans multiple machines simultaneously in seconds, with zero disruption to active cashier billing operations.
  • Results are displayed live on a simple Tkinter desktop interface and can be exported with one click into Excel (.xlsx) or CSV reports.
  • Packaged via PyInstaller into a single standalone .exe file, allowing operators to run it immediately with zero setup or software installation.
