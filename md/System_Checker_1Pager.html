SYSTEM CHECKER

Problem

Manual terminal logins across store POS counters create slow turnaround, high operational overhead, and blind spots during release audits.

Solution

Unified Windows console for mass property updates, tender URL verification, release version audits, and privileged RBAC command execution.

Impact

Zero manual PuTTY logins, instant store-wide property changes, sub-second URL checks, isolated offline tills, and full Excel audit logs.

Scale

Parallel multi-threaded execution across up to 100 POS counters per store and batch multi-store queues with bounded SSH concurrency.

1. Core Capabilities

  • Property Inspection & Mass Updating: Remotely inspect any configuration key (timeouts, server URLs, store IDs, language settings) across all POS counters in parallel, and push updated values store-wide in a single click with automated safety backups.
  • Payment & Tender URL Verification: Concurrently test external payment gateway and tender integration endpoints (PineLab, Paytm, internal bank/loyalty APIs) from the perspective of each individual till, verifying network reachability, response codes, and latency.
  • Delivery & Release Version Auditing: Inspect WAR archive sizes, build timestamps, and runtime delivery tokens across Back Office servers (.15) and POS tills (.112+), immediately highlighting exact version matches, mismatches, or offline systems in separate columns.
  • Daily Command Catalog & Privileged RBAC: Execute routine operational commands from a pre-configured, one-click catalog (cache clearing, process status, disk checks), backed by a dual-tier Role-Based Access Control (RBAC) model allowing privileged admins to run unrestricted fleet commands.

2. Technical Specifications

Component / Capability Technical Design & Operational Specification
Property Management Parses key/value `.properties` files across Linux counters; performs single-key inspection and atomic multi-till updates with automated `.bak.` rollback generation.
Tender URL Probing Performs concurrent HTTP/socket connection probes against payment endpoints (PineLab, Paytm, ERP APIs); tab-autocompletes aliases and measures round-trip response status.
Delivery Version Auditing Multi-threaded inspection of `.war` file byte size, filesystem modification date, and internal delivery version properties; deterministic ordering (Store → BO → Tills 1..N).
Command Catalog & RBAC Dual-tier access model: standard operators access a whitelisted routine catalog (cache clear, status); elevated admin mode unlocks unrestricted command execution.
Network & Concurrency Paramiko SSHv2 (Port 22 WAN) with CIDR subnet authorization; bounded concurrency (1-10 stores, up to 100 tills/store, capped at 100 global concurrent connections).
Client Runtime & Viewport Self-contained Windows executable (.exe, zero client dependencies); 100-row anti-lag viewport optimized for 14-inch laptop trackpads, preserving 100% of audit data for Excel (.xlsx).
